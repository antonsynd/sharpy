## Context

Batch 7 is one contract stated four ways: **an emitted construct is valid in every host context it can appear in, or the construct is refused by name in that context — never an ICE.** Four constructs violate it at HEAD: a module-level member reference that is spelled bare and collides with a namespace or with the module class itself (#1683 `Poison()` under `using static Poison.Lib` → CS0118; #1802 `Foo.Foo.K` inside the file-named class → CS0117); a dataclass or struct field whose default is a collection literal (the dataclass host is now a clean SPY0400 refusal since plan C, the STRUCT host still emits the literal as a C# default parameter → CS1736); a comprehension (or walrus) in a class-body, struct-body or module-level initializer, where no local ledger exists (SPY0909) and in an `__init__` self-assignment whose hoisted temp is dropped (CS0103); and `super().__op__(x)` inside an operator dunder, which emits `base + other` in both the instance `_Impl` split (CS0175) and the static inline (CS1511) because the choice between them is made by a kind-enumerating AST walker with a silent default. Nested `union` / `delegate` / `type` declarations in a type body are the fifth member: the parser accepts them and three switches agree on a four-kind universe, so the user sees "symbol not found" downstream (R-I: support them).
