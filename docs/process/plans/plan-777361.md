## Design Decisions

No rule below reads a builtin or type name; a rung applies only in D8.
- **D1 (module variables are declared first; Semantic).** `NameResolver.ResolveDeclaration` declares every module-level `VariableDeclaration`, annotated or `auto`, as it does a `const`; `TypeChecker.CheckVariableDeclaration` completes that symbol. A module `let` (SPY0340) and a second declaration of the name (#2125) keep today's verdicts (P21b). Predicates: no module-level `VariableSymbol` is created by `TypeChecker`; a variable's export is its declared symbol, cold and warm, so the identity-bridge arm of `ImportedStaticFacts.ImportedStorage` and `SemanticBinding`'s module-value map are deleted (its first arm stays).
- **D2 (a read is typed whatever the order; Semantic).** `CheckModule` resolves every declared type before it checks a body or an initializer: annotated module variables and module properties beside the consts, and each type's annotated members (fields, consts, properties, method signatures, union cases), nested types included. An unannotated module-level or type-level value is checked on its first read, in its own declaration's scope state, under an in-progress mark; a read that re-enters its own inference stays `Unknown` as today and adds no refusal (the cycle graph's SPY0278 is a ring's). Predicate: no read of a declared module-level or type-level name is `Unknown` because of where the declaration stands.
- **D3 (one class-body rule: N1, N2, N4, N7).** `TryResolveClassBodySiblingRead` decides a bare read of a member its type body declares by four facts: the member's level (type or instance), its order against the reader, whether a binding outside the body holds the name, and the position. Earlier: the member. At-or-after with an outer binding: SPY0619 in every position and for every member kind, instance included, judged before the kind refusal and SPY0401. At-or-after with none: the member, a forward read (N3); a self read is the cycle graph's. Outside N2 an instance member keeps its kind refusal and never yields, a parameter default keeps SPY0401 for a non-constant, an inherited member R1 (b). Deleted: F1's refusal, F2's yield, the `const` exemption in `IsDeclaredLater`, `ReportAmbiguousLaterConstReads`. Predicate: the verdict never reads `IsConstant`, the compile-time fact or the spelling.
- **D4 (bodies do not see class variables: N1, R-KG).** `Scope.ResolveName` crosses a type body from a nested type's body as from a function-like scope: no field, `const` or property of an enclosing type binds there bare. The crossing is variable-only, as today: a type, alias, type parameter or function still binds. `ClassifyClassBodyReadPosition` names three more positions — a nested type's body, a lambda in an initializer, a comprehension's body (all but its first iterable) — each with its phrase in the one SPY0200 steer. With an outer binding the read is that binding (R-Y), recorded through `SetModuleAccessCrossesClassMember` for an imported name as for a module variable. Predicate: every scope kind between a read and a type body is classified, with no default arm.
- **D5 (one callee resolver).** A bare callee resolves by the scope walk a bare read uses and dispatches on the symbol it bound, whatever an outer binding of the name is. The 33 direct `LookupFunctionOverloads` / `BuiltinRegistry.GetFunction` / `GetFunctionOverloads` sites in `TypeChecker*.cs` go behind it; a census test pins the remainder at the helper's own. A constructor's overload set is the whole body's.
- **D6 (N2 at module level; R-LJ).** A read evaluated at load — a module-level or class-level initializer or default, never a function body — of a builtin name its module declares at or after the reader is SPY0619. An import its module redeclares stays SPY0204 at the declaration.
- **D7 (R-QI).** A module variable, a `@static` field, and a module or `@static` auto-property with no initializer is SPY0620 at its declaration, whatever its type and host; the steer names `x: T = <value>` and `x: T | None = None`. Untouched: an instance field, a local `x: T`, a property with accessor bodies.
- **D8 (#2432; Semantic, Validation, CodeGen).** One answer per name the checker bound, for the identifier and member hooks, under every spelling (N7). True: a `const` whose fact is true; an int enum's member and its `.value`; and — rung 3: a referenced assembly's constant has no Sharpy symbol — a literal field of a referenced type or module (a module's by discovery's `IsConst`; a type's or enum's by `FieldInfo.IsLiteral`, through `ClrTypeHelper`). False: every other bound name (a `@static` member, own or inherited; a module variable, property or function; a string enum's member, any `.name`; a CLR static that is no literal). The shape rule keeps only what the checker did not bind. Every `IsAdmitted` call passes the answer: a `const` handed a non-constant is a computed constant, never C#'s `const`; a struct auto-property is a constructor parameter only for a constant (`MarkStructConstructorProperty`) and otherwise keeps its initializer and runs; the validator judges an enum member's value (a new `AdmissionTable` row), pushes interface and union hosts on `_enclosingTypes`, and refuses an attribute argument under SPY0425, each argument first checked by the checker as an expression in the scope its declaration stands in (a member's attribute in its type's body, so D3 and D4 decide its bare names) and printed by `GenerateAttributeArgumentExpression`'s ordinary read route. A `ComparisonChain` is admitted when each link is. Predicate: no expression reaches C# as a non-constant in a constant position, and no constant admitted today is refused.
- **D9 (codes).** SPY0619 (N2; the text carries both readings and the qualified spelling) and SPY0620 (R-QI); SPY0618 retires. T8 edits, in one commit, the table's rows, the `Expect*` arms that mirror them and `AdmittedRefusals`: D3's N2 cells leave `kind:instance-at-initializer` and `SPY0401`, N2 admits SPY0619 alone, N2-module SPY0619 and SPY0204, `kind:enum-member-constant` SPY0401, `N1-arity` names its code; S0b's R-QI cells, which admit none today, admit SPY0620.
- **D10 (an alias names a type that exists; owner).** An alias whose target names a missing type — as the name itself, inside a wrapper, type argument or callable, dotted, or in a generic alias's body — is SPY0202 at the alias, at every site (module, type body, function, block), named or not: both binders resolve the target where the alias is declared, expanding none that reaches its own alias (#2769, unruled: unused, it still runs). Predicate: no declared alias's target names a missing type.
- **Out of contract:** a read above a same-scope local (P80); a store without `global` (P79); a walrus over `let` (P21b); `ALSO = RED` (#2069); a receiver read untyped at either order (#2417, S0b's 150 rows); `self.x` of a `const` (#2147, 17 rows); a self-reaching alias named by an annotation (#2769); the #2397 rows; `T !E` above its `E` (#2249); `from m import x` as a live alias (N6).
