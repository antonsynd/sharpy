## Design Decisions

No rule below reads a builtin or type name; a rung applies only in D8.
- **D1 (module variables are declared first).** `NameResolver.ResolveDeclaration` declares every module-level `VariableDeclaration`, annotated or `auto`, as it does a `const`; `TypeChecker.CheckVariableDeclaration` completes that symbol. A module `let` (SPY0340) and a second declaration of the name (#2125) keep today's verdicts (P21b). Predicates: no module-level `VariableSymbol` is created by `TypeChecker`; a variable's export is its declared symbol, cold and warm, so `ImportedStaticFacts.ImportedStorage` loses its identity-bridge arm and `SemanticBinding` its module-value map.
- **D2 (a read is typed whatever the order).** `CheckModule` resolves every declared type before it checks a body or an initializer: annotated module variables and module properties beside the consts, and each type's annotated members (fields, consts, properties, method signatures, union cases, a `@dataclass`'s generated members: rulings 30, 37), nested types included. #2802's fix lands with it: the later form still prints `D`. An unannotated module-level or type-level value is checked on its first read, in its own declaration's scope state, under an in-progress mark; a read that re-enters its own inference stays `Unknown` as today and adds no refusal. Predicate: no read of a declared module-level or type-level name is `Unknown` because of where the declaration stands.
- **D3 (one class-body rule: N1, N2, N4, N7).** `TryResolveClassBodySiblingRead` decides a bare read of a member its type body declares by four facts: the member's level (type or instance), its order against the reader, whether a binding outside the body holds the name, and the position. Earlier: the member. At-or-after with an outer binding: SPY0619 in every position and for every member kind, instance included, judged before the kind refusal and SPY0401. At-or-after with none: the member, a forward read (N3); a self read is the cycle graph's. Outside N2 an instance member keeps its kind refusal and never yields, a parameter default keeps SPY0401 for a non-constant, an inherited member R1 (b). Deleted: F1's refusal, F2's yield, the `const` exemption in `IsDeclaredLater`, `ReportAmbiguousLaterConstReads`. Predicate: the verdict never reads `IsConstant`, the compile-time fact or the spelling.
- **D4 (bodies do not see class variables: N1, R-KG).** `Scope.ResolveName` crosses a type body from a nested type's body as from a function-like scope: no field, `const` or property of an enclosing type binds there bare. The crossing is variable-only, as today: a type, alias, type parameter or function still binds. `ClassifyClassBodyReadPosition` names three more positions — a nested type's body, a lambda in an initializer, a comprehension's body (all but its first iterable) — each with its phrase in the one SPY0200 steer. A lambda's parameter default, `lambda` or arrow, is not its body: in a class-level initializer D3 decides it, as a `def`'s (ruling 19). With an outer binding the read is that binding (R-Y), recorded through `SetModuleAccessCrossesClassMember` for an imported name as for a module variable. Predicate: every scope kind between a read and a type body is classified, with no default arm.
- **D5 (one callee resolver).** A bare callee resolves by the scope walk a bare read uses and dispatches on the symbol it bound, whatever an outer binding of the name is.
