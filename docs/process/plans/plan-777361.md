## Design Decisions

Python is evidence where it runs the same program: a NameError by order only becomes a running program (N1 + N3), a different meaning a refusal (N2). D7 and D8 are the tie-breaks' compile error over a silent default or a C# error. No rule below reads a builtin or type name; a rung applies only in D8.
- **D1 (module variables are declared before any read; Semantic).** `NameResolver.ResolveDeclaration` declares every module-level `VariableDeclaration`, annotated or `auto`, as it does a `const` (a module `let` stays SPY0340, P21b); `TypeChecker.CheckVariableDeclaration` completes that symbol and creates none at module level. A second declaration of the name keeps today's verdict (#2125, P21b). Predicates: no module-level `VariableSymbol` is created by `TypeChecker`; a module's export of a variable is its declared symbol on a cold and a warm build, so `ImportedStaticFacts.ImportedStorage` is deleted.
- **D2 (a read is typed whatever the order; Semantic).** The annotated module variables join `CheckModule`'s const type pre-pass. A module-level or type-level value with no annotation is checked on its first read, in its own declaration's scope state, under an in-progress mark; a read that re-enters its own inference is SPY0240 with the annotate steer. Predicate: no read of a declared module-level or type-level name is `Unknown` because of where the declaration stands.
- **D3 (one class-body rule: N1, N2, N4, N7).** `TryResolveClassBodySiblingRead` decides a bare read of a member its type body declares by four facts only — the member's level (`const` / `@static`, or instance), its order against the reader (earlier, or at-or-after), whether a binding outside the body holds the name (module, enclosing scope, import, builtin), and the position. Earlier: the member. At-or-after with an outer binding: SPY0619, in every position and for every member kind, instance included — N2 is judged before the kind refusal and before SPY0401. At-or-after with none: the member, a forward read (N3); a self read is the cycle graph's SPY0278. Where N2 does not apply an instance member keeps its kind refusal and never yields, a parameter default keeps SPY0401 for a non-constant, and an inherited member keeps R1 (b). Deleted: F1's refusal, F2's yield, the `const` exemption in `IsDeclaredLater`, `ReportAmbiguousLaterConstReads`, SPY0618. Predicate: the verdict never reads `IsConstant`, the compile-time fact or the spelling.
- **D4 (bodies do not see class names: N1, R-KG).** `Scope.ResolveName` crosses a type body from a nested type's body as it does from a function-like scope, so no enclosing type's symbol binds there. `ClassifyClassBodyReadPosition` names three more positions — a nested type's body, a lambda in an initializer, a comprehension's body (all but its first iterable) — each with its own phrase in the one SPY0200 steer (`Outer.s` where that compiles, no steer where nothing does). With an outer binding the read is that binding (R-Y), recorded through `SetModuleAccessCrossesClassMember` for an imported name as for a module variable. Predicate: every scope kind between a read and a type body is classified, with no default arm.
- **D5 (one callee resolver).** A bare callee resolves by the scope walk a bare read uses — local, parameter, class-body sibling at a class-body position, module, builtin — and dispatches on the symbol it bound. The 33 direct `LookupFunctionOverloads` / `BuiltinRegistry.GetFunction` / `GetFunctionOverloads` sites in `TypeChecker*.cs` go behind it; a census test pins the remainder at the helper's own. A constructor's overload set is the whole body's.
- **D6 (N2 at module level; R-LJ).** A module-level initializer or property default that reads, at load, a builtin or imported name its module also declares at or after the reader is SPY0619. A function body is not such a position.
- **D7 (R-QI).** A module variable, a `@static` field, and a module or `@static` auto-property with no initializer is SPY0620 at its declaration; the steer names `x: T = <value>` and `x: T | None = None`. Untouched: an instance field, a local `x: T`, a property with accessor bodies.
- **D8 (#2432; Validation).** `ConstantPositionValidator` judges an enum member's value (a new `AdmissionTable` row) and pushes interface and union hosts on `_enclosingTypes`. `IsMemberConstAdmissible` answers for every member access the checker bound, by what the member is: true for a `const` whose fact is true through any receiver, for an enum member and its `.value`, and — rung 3, since a constant in a referenced assembly has no Sharpy symbol — for a CLR literal field read through `ClrTypeBridge`; false for a `@static` field, property or method, own or inherited. The shape rule keeps only what the checker did not bind. A `ComparisonChain` is admitted when each link is. Predicate: no expression a constant position admits is CS0133 or CS1736, and no constant it admits today is refused. **Open, the owner's:** the harness tags 9 such cells must-refuse (rows citing #2423: an enum member's `.value`, a literal `const` through a subclass name; each runs, and python prints the same where it runs); D8 keeps them running, so their tags move only on the owner's word.
- **D9 (codes).** SPY0619 (N2; the text carries both readings and the qualified spelling) and SPY0620 (R-QI), each with its `DiagnosticExplanations` entry; SPY0618 retires. SPY0200 stays where no binding is visible at the position. In the table a read at-or-after its member under an outer binding is N2's whatever its target or position (381 cells leave `kind:instance-at-initializer`, 169 leave `SPY0401`), N2 and N2-module admit SPY0619 alone, and `kind:enum-member-constant` SPY0401.
- **D10 (open, the owner's).** `type K0 = nosuch`, unused, compiles and runs today; it is refused at the alias (SPY0202) only on the owner's word, and until then it is no cell of this plan.
- **Out of contract:** a read above a same-scope local (R-KX, P80); a store without `global` (P79); a walrus over `let` (P21b); `ALSO = RED` (#2069, P23); an untyped `@static property` read (#2417); the #2397 rows (P16); `T !E` above its `E` (its row cites #2249, P52); `from m import x` as a live alias (N6).
