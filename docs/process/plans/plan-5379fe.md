## Design Decisions

1. **One classifier, one site vocabulary.** `ClassifyTypeTestAnnotation`/`DecideBoundTypeTest` becomes the ONLY three-arm decider; `ClassifyResolvedTypeOperand` (isinstance) is reduced to "resolve the spelling to `(TypeSymbol, spelled type arguments)` and call the shared decider" — the `#912` erasure arm, `CollectionErasure`, `TypeTestLoweringKind.ErasedBuiltinCollection` and `BuildIsInstanceNarrowedType`'s default-`object` vector are DELETED (not gated). A `TypeTestSite` enum {Pattern, Isinstance, Cast, Except} replaces the `siteNoun` string + `erasure` flag and selects the refusal's steer spelling. Arms: (1) fill from the subject (`FillTypeArgumentsFromSubject` — closed generic, `T | None` payload, nested element/field type, `array[T]` interop for `list`), (2) explicit type arguments resolved through `TypeResolver.ResolveTypeAnnotation` (which already knows enclosing type parameters — cell (h)), (3) open subject (`object`, type parameter, non-filling) → SPY0345 with the site's steer. The type-parameter subject is OPEN for every form (today's SPY0361 on patterns goes away; the compatibility check runs only on a decided closed type).
2. **Arm 3 reuses SPY0345, no new code.** SPY0345 (`OpenGenericTypeTest`) already says "'list' is a generic type, so it does not name a single type to test against, and nothing at this <site> determines its type arguments" with a `list[...]` remedy — that IS the ruling's refusal. Allocating a second code for the same fact would give one family two codes (the #1855 lesson). The message gains the concrete steer per site: pattern `case list[int](xs)`, sequence `case list[int]([1, 2])`, isinstance `isinstance(x, list[object])` ("`list[object]` matches what `json.loads` and other `object`-typed producers build; a `list[int]` matches only a list constructed as `list[int]`"). `BuildPatternOpenGenericRemedy`'s "a pattern cannot name type arguments" text is deleted. The `DiagnosticExplanations` entry for SPY0345 is rewritten to the three arms; SPY0125 is marked **Retired** (explanation kept, emission site deleted — `DiagnosticCodeEmissionSiteTests` verifies).
3. **Exact constructed-type semantics (R-C).** `isinstance(o, list[int])` / `case list[int](xs)` lower to `o is Sharpy.List<int>` and match only a value constructed as `list[int]` (b05 already); no structural or element scan, ever.
