## Defect Class

- **Violated contracts (one per phase):**
  1. *Resolution priority* (Phase 1): a name that the builtin channel owns never resolves through the CLR-interop fallback, and the fallback's namespace order is the priority for every assembly, not only for the two `Type.GetType` can see.
  2. *Qualification* (Phase 1): every CLR type name the emitter writes — reference, construction, receiver-position chain, import alias target, base list — is `global::`-qualified from the reflected `System.Type`, so no `using` set can make it ambiguous.
  3. *Static receiver* (Phase 2): every spelling of a type-name receiver — imported CLR name, builtin alias, module-qualified chain — reaches the SAME static seam (`ClrReceiverKind.StaticType` at the resolver; `ClrStaticCallType` at the call) and gets its three outcomes (typed / collapsed property call / SPY0203), and the builtin unions' qualified case spellings are refused by name there (R-S).

Arm (b): the loop becomes namespace-outer / (`Type.GetType` then assembly sweep)-inner so priority is a total order; where two `List<>` are legitimately visible, the emitted name is the `global::`-qualified one (Decision 2), which is what makes (b) safe where the reverted attempt was not.
2. **One `global::` name-emission helper (#1765; consumed by P6 #1683/#1802).** `TypeSyntaxMapper.QualifyFromSymbol` returns `global::` + `ClrNameHelper.ToCSharpQualifiedName(clrType.FullName)` for EVERY CLR-backed `TypeSymbol` in every position (delete the ProjectNamespace and position conditions of the CLR arm; keep the Sharpy-namespace arm's behavior, which already does this). [CORRECTED: two further name-emission arms are folded into the same helper or the contract "every position" is false by construction — the identifier-as-type-name arm `RoslynEmitter.Expressions.cs:346-368` (a `TypeSymbol { ClrType }` in expression position: the imported-alias receivers `Path.combine`, `Math.max`, `DateTime.now`; today `global::` only under Sharpy-namespace or ProjectNamespace, else the bare name that the `using` alias happens to resolve) and the builtin-registry arm `TypeSyntaxMapper.cs:608-629` (`ClrType.Name` bare for `System.*` outside a ProjectNamespace).
