# Optional-needle membership: `T | None in container`

## Context

#2635: a value-typed `T | None` needle is refused (SPY0222) by `in`/`not in`, where CPython 3.15 answers `False`/`True` for `None`. Found when `socket.error.errno` became `int | None` (PR #2636).

## Current State

- Value payloads (the numerics, `decimal`, `bool`, `bytes`, `tuple[int, int]`, a user `struct`) as `T | None`: SPY0222 in all 14 element-typed containers and in `range`.
- An int-backed enum (`Color`) is a C# `enum`, but `UserDefinedType.IsValueType` (`SemanticType.cs:490`) is true only for `TypeKind.Struct`. So `Color | None` passes `NullableType.IsAssignableTo` (`:749`) into a `Color` slot: SPY0908 as a needle, an argument, an assignment, a return, and after `if d is not None:`.
- The literal `None` into a non-optional slot is SPY0222 (ruling A) except in the CLR-backed containers (SPY0908, runs, or `NullReferenceException`).
- Reference payloads (`str`, class, interface, union, delegate, the IP addresses) as `| None` pass `:749`; their `None` reaches `Contains(null)`: `False` for the scan containers, `ArgumentNullException` in `Counter` and `str` (CPython: `False`, TypeError), `NullReferenceException` in the IP networks and `False` in `EmailMessage` (CPython: `AttributeError`).

## Design Decisions

- **D1. Lift the needle.** `ClassifyMembership` (`TypeChecker.Expressions.Operators.cs:1578`) decides in this order: D2's subsequence test; the existing `IsArgumentAssignable(needleType, elementType)` test (plain path, unchanged); then the lift: a `NullableType` needle whose underlying type `IsArgumentAssignable` to the slot is accepted. A needle the slot already holds (`x: int | None` into `list[int | None]`) keeps the plain path; the `*OfOptional/Optional` cells (`None` → `True`) pin that order.
  - A lifted value-type needle (`NullableType.IsValueType`; with D7, an int-backed enum too) returns `OperatorLoweringKind.MembershipNoneIsFalse`. The binary site records it with `SetOperatorLowering` (`SemanticInfo.cs:2148`; `_operatorLowerings` is already in `MergeFrom`, `:2514`); the chain site records it in its `ComparisonLinkLowering` (dead until #2648).
  - The emitter `In`/`NotIn` arm (`RoslynEmitter.Expressions.Operators.cs:186`) reads the kind and emits `Builtins.ContainsOptional(x, y, static (c, n) => c.Contains(n))`, negated for `not in`; the container is projected as today. The Core helper (a new file beside `Map.cs`) is `needle.HasValue && contains(container, needle.Value)`, generic over `T : struct`.
  - Rung 2 for the runtime body; rung 1 cannot carry it (a CLR `Contains(T)` takes no `T?`). The choice of helper is a checker fact, so it is recorded (Rule 2).
  - **Predicate:** `ClassifyMembership` is the only place that decides either membership kind, and the emitter's `In` arm reads it (through `OperatorLoweringOf`); no type test is added in `CodeGen/`.
  - A reference needle records nothing, lifted (`Tone | None` into a `str` slot, D8) or not: its `None` reaches the receiver's `Contains(null)`, which answers (D6).
  - **The literal `None`** (ruling A) gets no lowering: SPY0222 into a non-optional slot at both arms, plain membership into an optional element.
- **D2. Subsequence containers raise.** A container is a subsequence container when its CLR type (`BuiltinType.ClrType`, or `UserDefinedType.Symbol.ClrType` for `bytes`) has a public `Contains` that takes its own type (`string.Contains(string)`, `Bytes.Contains(Bytes)`). Decided by CLR reflection through `ClrTypeHelper`, not by name (rung 3).
  - For such a container, a `NullableType` needle whose underlying type is assignable to a slot (value or reference payload) records `MembershipNoneRaises`. This runs before the assignability test, because `str | None` into `str` passes that test today and would return early.
  - The emitter emits `Builtins.ContainsNoneRaises(x, y, static (c, n) => c.Contains(n))`. Overloads for a value needle and a reference needle throw `TypeError` on `None` (ruling 2; message DEVIATION by default).
  - **Predicate:** `x: str | None = None; x in "abc"` raises a TypeError that `except TypeError:` catches; so does `t: Tone | None = None; t in "abc"`.
- **D3. The CLR-backed slot (#2647).** `ClassifyMembership` resolves the needle slots of a CLR-backed non-generic container from its public single-argument `Contains` overloads: a slot-set sibling of `ResolveMembershipElementType` (`:1617`), whose CLR arm (`:1684`) matches only a `BuiltinType` and takes `FirstOrDefault`. It reads a `UserDefinedType`'s `Symbol.ClrType` through `ClrTypeHelper` and accepts a needle assignable to any slot.
  - `ResolveMembershipElementType` still returns none for them, so the site's store (`:62`) pushes no slot, as today.
  - `bytes`' slots are `int` and `bytes` (ruling C); the spec row is amended (D5).
  - A needle no overload takes is refused with SPY0222 and its cast steer (`membership-needle-type-mismatch`); so is the literal `None` (ruling A).
  - **Predicate:** `n: int64 = 1; n in bytes([1])` and `"x" in IPv4Network("10.0.0.0/8")` are SPY0222, never SPY0908; `bytes([1]) in bytes([1, 2])`, `1 in bytes([1, 2])` and `(b1 if c else b2) in bytes([1, 2])` print `True`; `None in EmailMessage()` is SPY0222.
- **D4. Evaluation order.** Both helpers take the needle before the container, so lifted cells evaluate `x` then `y`, as Python does. Every non-lifted cell keeps `y.Contains(x)`; #2645 stays open.
- **D5. Spec.** In `docs/language_specification/membership_operators.md` › Needle Type, add a "None needles" paragraph. A `T | None` needle is accepted: `None` is no element's equal, TypeError for `str`/`bytes` (D2), the receiver's answer for a CLR container (D6). The literal `None` is refused unless the element type is optional (ruling A). Executed examples whose output differs under the bug.
  - The Container kinds row for `bytes` reads `int` or `bytes` (subsequence test), per ruling C.
  - In `docs/deviations.yaml`, state that `membership-needle-type-mismatch` covers the literal `None` into a non-optional slot (ruling A) and not a `T | None` needle (rulings 1–2).
  - That row's rationale becomes ruling B's: the slot holds `int` and a needle must convert implicitly (`True in range(3)` is True in Python), cured by a cast. Its example names a `bool` or `decimal` needle.
- **D6. Receivers answer `None` as CPython does.** Rung 2, in Stdlib C#: `Counter.Contains(null)` returns `False`, and `IPv4Network.Contains`, `IPv6Network.Contains` and `EmailMessage.Contains` raise `AttributeError` on `null` (CPython: `None.version`/`None.lower()`; message DEVIATION by default). `Namespace.Contains(null)` already returns `False`, as CPython.
  - **Predicate:** `a: IPv4Address | None = None; a in IPv4Network("10.0.0.0/8")` raises an `AttributeError` that `except AttributeError:` catches; `s: str | None = None; s in Counter[str](["a"])` prints `False`.
- **D7. Enum value-ness (R-NY).** `UserDefinedType.IsValueType` (`SemanticType.cs:490`) is true for `TypeKind.Struct` and for `TypeKind.Enum` when `Symbol.IsStringEnum` is false. `IsStringEnum` is set at declaration (`NameResolver.Declarations.cs:432`), so it is known before any type check; a CLR enum is never string-backed. A string-backed enum lowers to a class and stays a reference type. No reader is edited.
  - **Predicate:** with `d: Color | None`, `g(d)` into `c: Color` is SPY0220 and `return d` from `-> Color` is SPY0260, never SPY0908; `if d is not None: g(d)` runs; `d in [Color.RED]` prints `False` for `None` (D1). `Tone | None in [Tone.A]` still runs.
- **D8. A string-backed enum converts `None` to `None`.** The emitted `implicit operator string` (`RoslynEmitter.TypeDeclarations.cs:1473`) returns null for a null operand instead of dereferencing it. It is the generated class's body (`SyntaxFactory` only, no type decision); no lower rung declares the conversion. It changes every `Tone | None` to `str` conversion: `None` flows on, as a `str | None` does, where it threw. No `.expected.cs` snapshot contains the operator, so none moves.
  - **Predicate:** `t: Tone | None = None`: `t in ns` (argparse `Namespace`) prints `False`; `t in EmailMessage()` raises `AttributeError` (D6).
