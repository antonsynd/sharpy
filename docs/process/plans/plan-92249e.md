## Design Decisions

**D1 — operator carrier: one interface, four node kinds.** `internal interface IIrOperatorSite { OperatorLoweringKind Operator { get; } SemanticType? NarrowTo { get; } }` in `src/Sharpy.Compiler/Lowering/IrNode.cs`. No rung: the pass copies a recorded fact; no name-keyed rule.
- `IrOperatorExpression(Expression Ast, OperatorLoweringKind Operator, SemanticType? NarrowTo, SemanticType? Type, TextSpan Span, ImmutableArray<IrNode> Children) : IrExpression, IIrOperatorSite` — a `BinaryOp` (not `==`/`!=`, not a folded power), `UnaryOp` or `FunctionCall` whose key has a table entry. `Ast` is kept because `ConstFoldPass` folds from it.
- `IrEqualityComparison` gains a required `OperatorLoweringKind Operator` (the `ReflectedOperands` entries of `TypeChecker.Expressions.Operators.cs:217`); `NarrowTo` is null.
- `IrOperatorAssignment(OperatorLoweringKind Operator, SemanticType? NarrowTo, TextSpan Span, ImmutableArray<IrNode> Children) : IrStatement, IIrOperatorSite` — an `Assignment` with an entry that is neither a collection mutation nor a store wrap.
- `IrOptionalStoreWrap` gains the two members as required parameters.
- **Precedence on `Assignment`:** mutation, wrap (with operator), operator, opaque. **Predicate:** the checker returns from the mutation path before any `SetOperatorLowering` (`TypeChecker.Statements.cs:433` precedes `:510`), so an `IrCollectionMutation` key never has an entry; the sweep measures it.
- **Predicate (folded power):** `TryFoldIntegerPower` returns at `TypeChecker.Expressions.Operators.cs:236-239`, before every non-comparison `SetOperatorLowering`, and `**` is not a comparison, so an `IrConstant` key has no entry; the sweep asserts it.
- **Absent = `Native`:** a key with no entry stays opaque and the emitter helper answers `(Native, null)`. That is the table's own convention (`ConstEligibility.cs:612`: `lowering == null || Kind is Native`; `RoslynEmitter.Expressions.Operators.cs:290`: `?.Kind ?? Native`), not a new default.

**D2 — pass and accessor.** `SemanticInfo.GetOperatorLowering` is renamed `GetOperatorLoweringForIr` (the four-accessor precedent); callers after the rename: `LoweringPass`, `ConstEligibility.cs:611`, `TypeChecker.Statements.cs:557`, tests. The 20 checker writes stay (transport). `LowerExpression` gains one arm after the folded-power and equality arms; `LowerEqualityComparison` and the `Assignment` path of `LowerStatement` read the entry. `IrTreeRewriter` gains an arm per new kind mirroring the opaque arms (`IrTreeRewriter.cs:52,78`); `ConstFoldPass` treats `IrOperatorExpression` as it treats `IrOpaqueExpression` (`ConstFoldPass.cs:49`), rebuilding the same kind when children change.

**D3 — emitter.** One helper beside `IrNodeFor` (`RoslynEmitter.Expressions.Access.cs:2186`): `OperatorLoweringOf(Node ast)` returns the `IIrOperatorSite` at the key, looking through `IrOptionalWrappedElement { Children: [IIrOperatorSite] }`, else `(Native, null)`. All 17 reads call it; the rename makes a missed read a build error. No decision moves into the emitter: each site keeps its `switch` on the kind.

**D4 — type-test split (R-MX: the type half stays a type fact).** The table keeps its key and becomes `_typeTestTypes : Node → TypeTestType`, where `TypeTestType(SemanticType TestType, IReadOnlyList<SemanticType>? Alternatives = null)` replaces `TypeTestLowering`; `TypeTestLoweringKind` is deleted (`ExceptionAlternation` ≡ `Alternatives != null`: the one writer that sets it is the one writer of that kind). Rung: none (rename of a recorded fact).
- Accessors: `SetTypeTestType(Node, SemanticType, IReadOnlyList<SemanticType>? alternatives = null)`; `GetTypeTestType(Node) : SemanticType?` (bind/test type); `GetExceptAlternativesForIr(Node) : IReadOnlyList<SemanticType>?`. The old three names are deleted, so every reader is a build error until moved. Checker `Set\w*Lowering(` 70 → 59; pin stays 84 (a type table, R-MX).
- **Why not derive `Alternatives` from the element records:** an element the classifier declines is resolved by `ResolveUnnamedExceptType` (`TypeChecker.Statements.cs:1987`) with no element entry, so element records are not total; the list is transported.
- `ExceptHandlerReachability.cs:189` drops its `Kind: ClosedType` conjunct. **Predicate:** it is called on `ElementsOf(handler.ExceptionType)`, which yields a tuple annotation's type arguments, never the tuple annotation the alternation arm keys (`TypeChecker.Statements.cs:1961` writes `annotation`), so the conjunct was always true there. `ExceptHandlerReachabilityTests` and `ExceptHandlerOrderDifferentialTests` are the check.

**D5 — alternation on the IR.** `IrPrunedTry` is renamed `IrPlannedTry` and built when a handler is covered OR is an alternation. `IrHandlerPlan(bool Emitted, ImmutableArray<bool> EmittedTypes, IrAlternationCatch? Alternation)`, `IrAlternationCatch(SemanticType BindAt, ImmutableArray<SemanticType> Alternatives)`.
- **Predicate (pass):** `handler.Name != null ∧ handler.ExceptionType is { } ann ∧ GetExceptAlternativesForIr(ann) is { } alts`, with `BindAt = GetTypeTestType(ann)`: the emitter's own condition (`RoslynEmitter.Statements.ControlFlow.cs:1787-1790`).
- Emitter: the alternation arm reads `IrNodeFor<IrPlannedTry>(tryStmt)?.Handlers[i].Alternation`; `GenerateAlternationCatchClause` takes the `IrAlternationCatch`. A try with neither stays opaque; a null plan reads "emit all, no alternation" as today (`RoslynEmitter.Statements.ControlFlow.cs:1748`).

**D6 — the five type hand-offs (contract item 1).** One emitter helper `TypeTestTypeSyntax(Node operand) : TypeSyntax?` = `MapTypeTestTypeName(GetTypeTestType(operand))`, replacing `MapTypeTestTarget`; the five sites keep their own fallback or throw. It is the emitter's only `GetTypeTestType` read: one new allowlist row `RoslynEmitter.Expressions.Access.cs | type-read | GetTypeTestType | 1 | cite=#2443` (212 → 213; the reflected `type-read` kind counts it without a scanner change; `allowlist_rows_seed` +1 by `--set-baseline` in the same commit). It replaces six reads no kind counted.

**D7 — guard for the `ForIr` convention.** `EmitterCarrierOnlyConformanceTests` gains a census: Roslyn syntax, every invocation whose member name ends `ForIr`, per directory; asserts 0 under `CodeGen/` and ≥ 6 under `Lowering/` (the positive control).
