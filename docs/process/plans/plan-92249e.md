## Design Decisions

**D1 — operator carrier: one interface, four node kinds.** `internal interface IIrOperatorSite { OperatorLoweringKind Operator { get; } SemanticType? NarrowTo { get; } }` in `src/Sharpy.Compiler/Lowering/IrNode.cs`. No rung: the pass copies a recorded fact; no name-keyed rule.
- `IrOperatorExpression(Expression Ast, OperatorLoweringKind Operator, SemanticType? NarrowTo, SemanticType? Type, TextSpan Span, ImmutableArray<IrNode> Children) : IrExpression, IIrOperatorSite` — a `BinaryOp` (not `==`/`!=`, not a folded power), `UnaryOp` or `FunctionCall` whose key has a table entry. `Ast` is kept because `ConstFoldPass` folds from it.
- `IrEqualityComparison` gains a required `OperatorLoweringKind Operator` (the `ReflectedOperands` entries of `TypeChecker.Expressions.Operators.cs:217`); `NarrowTo` is null.
- `IrOperatorAssignment(OperatorLoweringKind Operator, SemanticType? NarrowTo, TextSpan Span, ImmutableArray<IrNode> Children) : IrStatement, IIrOperatorSite` — an `Assignment` with an entry that is neither a collection mutation nor a store wrap.
- `IrOptionalStoreWrap` gains the two members as required parameters.
- **Precedence on `Assignment`:** mutation, wrap (with operator), operator, opaque. **Predicate:** the checker returns from the mutation path before any `SetOperatorLowering` (`TypeChecker.Statements.cs:427-432` precedes `:510`), so an `IrCollectionMutation` key never has an entry; the sweep measures it.
- **Predicate (folded power):** `TryFoldIntegerPower` returns at `TypeChecker.Expressions.Operators.cs:236-239`, before every non-comparison `SetOperatorLowering`, and `**` is not a comparison, so an `IrConstant` key has no entry; the sweep asserts it.
- **Absent = `Native`:** a key with no entry stays opaque and the emitter helper answers `(Native, null)`. That is the table's own convention (`ConstEligibility.cs:612`: `lowering == null || Kind is Native`; `RoslynEmitter.Expressions.Operators.cs:290`: `?.Kind ?? Native`), not a new default.

**D2 — pass and accessor.** `SemanticInfo.GetOperatorLowering` is renamed `GetOperatorLoweringForIr` (the five-accessor precedent); callers after the rename: `LoweringPass`, `ConstEligibility.cs:611`, `TypeChecker.Statements.cs:557`, tests.
