## Design Decisions

- **D1 — Layer:** every rule is a resolver / checker / validator / emitter rule over the AST and symbol table (rung N/A). ONE new diagnostic code, **SPY0617** `InterfaceAccessorsMustAgreeOnBody` (Semantic overflow; the next free code after SPY0616 @ 9fd3f4200), with a `DiagnosticExplanations.Semantic.cs` entry; **SPY0365 retires** into SPY0204 (D6). - **D2 — R-JG: the interface abstract × bodied refusal lives in the member seam, one arm.** `AccessorDeclarations` records, beside each slot, the BODY class of the half that filled it: `Abstract` (an auto half with NO default; a function-style stub `...`), `Bodied` (a function-style accessor with a body), `Defaulted` (an auto half WITH a default — the one class this arm never judges: under R-JL it is #2383's DIM-or-refusal and waits for P30).
