## Design Decisions

- **D2 — Alias redeclaration (#2360): the owner of "an alias re-declares a name" is the checker's `RegisterScopedTypeAlias` (the alias's only declarer at a function scope or block — P21e's one-owner rule); the fix compares DECLARATIONS, not names.** The guard becomes `if (existing is TypeAliasSymbol a && a.IsDeclaredAt(typeAlias)) return;` (the same node met again: class-body pre-registration + body pass) and otherwise falls into the existing "already defined" arm — SPY0204 "Type alias 'A' is already defined" when `reportHere` (function body, block, module block), silent at a declaring position (NameResolver already reported; a3/a4 stay ONE diagnostic). Rejected: (b) a validator arm keyed on alias names — the checker already owns alias-after-def (d3) and alias-after-variable (d9) with the same text; splitting alias-after-alias to a validator makes two owners for one verdict.
