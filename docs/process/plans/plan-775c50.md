## Design Decisions

Each **Departure** from the charter's emission (§3.20k; owner, Q6) is prototyped in C#, not compiler output.

- **D1 (#2420; Semantic).** Delete `ExecutionOrderAnalyzer.DetectInitializerDependencies`. Predicate: the `CodeGenInfo` of a module-level `VariableDeclaration` does not depend on what its initializer reads.
- **D2 (facts; Rule 2).** `CodeGenInfoComputer` records on `Symbol.CodeGenInfo`, and `SymbolSerializer` round-trips: per value `StaticStorage` ∈ {Const, Guarded, Plain} and a generic-host flag (a type parameter on its type or an enclosing one); per module `HasSweep`. Guarded = has an initializer and is no C# `const`: a module variable, a computed `const`, a property default, a `@static` field, in every host. No initializer: Plain, as today (owner, Q4).
- **D3 (runtime; rung 2).** `Sharpy.StaticInit` in Sharpy.Core (C# 9): ONE process-wide re-entrant lock. `Run(ref byte state, string name, Action init)`: a read or a store on the initializing thread raises `NameError` (owner, Q15); a throw restores Uninitialized and rethrows the ORIGINAL exception. `Load` runs a host's sweep (a module's or a closed generic type's) once under the lock; a failure is delivered once (to `Main` or the importer; on a lazy host to the use that started it), then uses retry per value. **Departure:** a type initializer calls `TryLoad`, which never waits for the lock. Predicates: no thread waits for the lock while holding a type-initializer lock; no use of a value returns while its initializer runs on that thread.
- **D4 (declaration shape; CodeGen).** A Guarded value is a backing field, a state byte (Uninitialized, Initializing, Assigned, Ready), `Init_x` and a property of the SAME C# name. **Departure:** a variable's or `@static` field's property returns by reference (`get { if (!Swept.Done) Slow_x(); return ref field; }`), a computed const's `ref readonly`; a property default keeps `get` / `set`. A read, a member or index store, a mutating call and a `ref` / `in` operand stay today's C#: each reads, so it initializes first. A plain store is `x_set(v)`, which marks an Uninitialized value Assigned — reads see it, and the sweep still runs the initializer at its position (`5 7`) — and raises on an Initializing one. Plain stores: every store site, the five AST nodes with a target, on a bare or qualified name; and an `out` operand naming the value, whose temporary `x_set` stores after the call (owner, Q12; `42 7`). `x op= e` is `x_set(x op e)`. Predicates: no user expression is left in a static initializer or constructor (C# `const` aside); an arm is picked by `StaticStorage`, never by a type; nothing but `x_set` stores a whole Guarded value.
- **D5 (sweep; CodeGen).** Declaration order, never dropped, on every host (owner, Q14). **Departure:** ONE `Swept` per module, none per non-generic class. The module's sweep runs in SOURCE order (R-JT): each import with `HasSweep`, each Guarded value, each non-generic type's values at the type's position; it stops at the first throw. A use of a type not yet reached initializes that one value, or keeps its plain store (A5). `Main` first requires its module and rethrows the original exception (owner, Q3); with no Sharpy entry point a module loads on its first use. A closed GENERIC type has the charter's own `Swept`: it sweeps its values in declaration order on its first use. **Departure:** inside a running initializer that use is one of a type not yet reached, and the sweep waits for the outermost initializer to return (its failure is thrown there; made at once, A5's read into a generic class raises). Such a closed type keeps a state check on every use (A12). Predicates: no closed type's sweep starts while an initializer runs on its thread; no accessor returns a value in a state below Assigned.
- **D6 (suspension; CodeGen).** C# keeps no returned reference across `await`. In an `async def` body a use other than a plain read or a plain store (an `out` operand's temporary crosses the `await`) is a statement `Ensure_x()`, then the backing field; which uses those are is a `SemanticInfo` fact (in `MergeFrom`). Predicate: no accessor's reference is live across an `await`.
- **D7 (operands; Semantic).** `TypeChecker.CheckModifiedArgument` refuses by the operand's resolved symbol (SPY0389; by shape today): a property under `ref` / `out` / `in`, in every host, default or not (owner, Q8); a `const` under `ref` / `out` (`parameter_modifiers.md`: the caller passes a variable). A variable under any modifier and a computed `const` under `in` run. Predicate: no operand the rule admits is a C# error after D4.
- **D8 (cycles; Validation).** One graph after type checking, at Order 251, replacing `StaticInitializerOrderValidator` and `TypeChecker.DetectConstantCycles`. Nodes: each Guarded value and each `const` with an initializer; reads resolve through the checker's bound symbols, never the spelling. Two edge sets, never mixed in one cycle. CERTAIN, between any nodes: a read in a slot the generator classifies `Always` (owner, Q7), so none in a `Conditionally` slot, a pattern or a nested function body; and a node's `out` operand naming itself in such a slot (Q15: a self-loop; no other store is an edge). LEXICAL, between `const`s only: any read (today's SPY0278 set). A node on a cycle of certain edges, or of lexical edges among `const`s alone, is SPY0278 (its text says "value" for a non-const): no lexical edge closes a cycle through a non-const node, and `5 7 6` keeps running. A cycle neither rule sees is D3's `NameError`. A test asserts the validator's slot map (total over the `Expression` subclasses and `BinaryOperator`) and node kinds equal to the generator's. Predicate: a cycle refused at compile time lies wholly among `const`s, or its every edge is evaluated whenever its initializer is, so initializing any of its nodes raises.
- **D9 (retirement; R-KD).** SPY0618 retires in D8's commit; `StaticInitializerOrderMatrixTests` flips by direction: forward cells run, self reads are SPY0278.
- **D10 (interop; rung 3).** A module variable becomes a by-reference C# property: a C# consumer uses it as before, its address too. Generated members carry `[CompilerGenerated]` and discovery skips them. For a module imported by reference it reads `StaticStorage` and `HasSweep` from Sharpy.Core attributes on the member and the load entry — never a name, nor the CLR shape (a C# library's own `ref` static property is Plain) — and the importer's sweep requires the entry at the import's position.
- **Out of contract:** a later module VARIABLE's visibility (SPY0200; N1, #2423); #2151's store arm (P79); a module variable declared twice (#2125, R-CY, P21b); a struct behind a PROPERTY (#2268); `+=` and a `for` target through a closed generic type, a qualified starred target (#2435's class; each excluded with its program).
