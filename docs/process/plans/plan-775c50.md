## Design Decisions
Principle (Q21): C# unless N3 forbids it. D3–D5 and each **Departure** from the charter's emission (§3.20k; Q6): the author's C# prototype, not compiler output.
- **D1 (#2420; Semantic).** Delete `ExecutionOrderAnalyzer.DetectInitializerDependencies`. Predicate: the `CodeGenInfo` of a module-level `VariableDeclaration` does not depend on what its initializer reads.
- **D2 (facts; Rule 2).** `CodeGenInfoComputer` records on `Symbol.CodeGenInfo`, and `SymbolSerializer` round-trips: per value `StaticStorage` ∈ {Const, Guarded, Plain} and a generic-host flag (a type parameter on its type or an enclosing one); per module `HasSweep`. Guarded = has an initializer and is no C# `const`: a module variable, a computed `const`, a property default, a `@static` field, in every host. No initializer: Plain, as today (Q4).
- **D3 (runtime; rung 2).** `Sharpy.StaticInit` in Sharpy.Core (C# 9): ONE process-wide re-entrant lock. `Run(ref state, name, init)`: on the initializing thread, a read of a value never given one raises `NameError` (Q15, Q21); a throw restores the state it found and rethrows the ORIGINAL exception. `Load` runs a host's sweep (D5) once under the lock; a failure is delivered once, to what required the host, then uses retry per value. **Departure:** a type initializer calls `TryLoad`, which never waits for the lock. Predicates: no thread waits for the lock while holding a type-initializer lock; no read returns a value never given one.
- **D4 (declaration shape; CodeGen).** A Guarded value is a backing field, a state byte, `Init_x` and a property of the SAME C# name. States: Uninitialized, Initializing, Assigned and Stored-initializing (the first two once stored to), Ready. **Departure:** a variable's or `@static` field's property returns by reference (`get { if (!Swept.Done) Slow_x(); return ref field; }`), a computed const's `ref readonly`; a property default keeps `get` / `set`. A read, a member or index store, a mutating call and a `ref` / `in` operand stay today's C#: each reads, so it initializes first. A plain store is `x_set(v)`, which marks the value stored: a read then returns it, and the initializer's result replaces it (Q14, Q21: before it `5 7`; inside it `1`, read back `6`). Plain stores: every store site, the five AST nodes with a target, on a bare or qualified name; and an `out` operand naming a value not yet Ready, whose temporary `x_set` stores on return (Q12; `42 7`). Once Ready it is the backing field, as C# and today (Q24; `42 42`, a callee's throw included): `x_out(out tmp, out spilled)` returns either by reference, by the value's state at the operand's place, so a failed or lock-losing sweep keeps no temporary. `x op= e` is `x_set(x op e)`. Predicates: no user expression is left in a static initializer or constructor (C# `const` aside); an arm is picked by `StaticStorage`, never by a type; a plain store is `x_set`, or a callee's through `out` on a Ready value.
- **D5 (sweep; CodeGen).** The charter's emission (Q17, Q18): ONE `Swept` per host (a module, a class with Guarded values, each closed generic type), one rule. A host sweeps whole, in declaration order, none dropped (Q14), to the first throw, when first required: by `Main` for its module (rethrowing the original: Q3); by an importer's sweep at the import's position (`HasSweep`); by the sweep around it at a non-generic class's line (SOURCE order, R-JT; nested too); or by the first use of one of its values. In its own running sweep a read of a value not yet reached initializes it, and a plain store is kept and replaced at its position. From anywhere else the host sweeps first: a store into a later class or closed generic type lands on its initialized value (`5 5`: today's). Accepted residue (Q18): that sweep runs ALL the host's initializers, and one reading back a value still Initializing raises (`class A: x = B.p` beside `class B: p = 1; q = A.x + 1`, A required first). Predicates: a use from outside a host's running sweep runs the whole sweep before it returns or throws; no accessor returns a value in a state below Assigned; the rule names no host kind.
