# P77 — N3: values ready before use

## Context

Rule N3 (`docs/design/name-resolution.md`): every non-constant module-level and `@static` value is initialized before its first read on every path; initializers run top to bottom, after imports and before `main`; a cycle is a compile error where visible, a run-time error otherwise; a throwing initializer is retried; a CLR default is never observed. Issues: #2422 (tracker), #2412, #2420.

## Design Decisions

D3–D5 leave the charter's emission (§3.20k) where a measured cell requires it (owner, Q6); each departure is prototyped in C#, not compiler output, and its cost is A12's.

- **D1 (#2420; Semantic).** Delete `ExecutionOrderAnalyzer.DetectInitializerDependencies`. Predicate: the `CodeGenInfo` of a module-level `VariableDeclaration` does not depend on what its initializer reads.
- **D2 (facts; Rule 2).** `CodeGenInfoComputer` records on `Symbol.CodeGenInfo`, and `SymbolSerializer` round-trips: per value `StaticStorage` ∈ {Const, Guarded, Plain} and a generic-host flag (a type parameter on its type or an enclosing one); per module `HasSweep`. Guarded = has an initializer and is no C# `const`: a module variable, a computed `const`, a property default, a `@static` field, in every host. No initializer: Plain, as today (owner, Q4).
- **D3 (runtime; rung 2).** `Sharpy.StaticInit` in Sharpy.Core (C# 9): ONE process-wide re-entrant lock. `Run(ref byte state, string name, Action init)`: re-entry on the initializing thread raises `NameError`; a throw restores Uninitialized and rethrows the ORIGINAL exception. `Load` runs a module's sweep once under the lock; a failure is delivered once (to `Main` or the importer; on a lazy host to the read that started it), then reads retry per value. **Departure:** a type initializer calls `TryLoad`, which never waits for the lock. Predicate: no thread waits for the lock while holding a type-initializer lock.
- **D4 (declaration shape; CodeGen).** A Guarded value is a backing field, a state byte (Uninitialized, Initializing, Assigned, Ready), `Init_x` and a property of the SAME C# name. **Departure:** a variable's or `@static` field's property returns by reference (`get { if (!Swept.Done) Slow_x(); return ref field; }`), a computed const's `ref readonly`; a property default keeps `get` / `set`. A read, a member or index store, a mutating call and a `ref` / `in` operand stay today's C#: each reads, so it initializes first. A plain store is `x_set(v)`, which marks an Uninitialized value Assigned — reads see it, and the sweep still runs the initializer at its position (`5 7`). Plain stores: every store site, the five AST nodes with a target (assignment and its unpacking leaves, `for`, `with … as`, comprehension clause, walrus), on a bare or qualified name; and an `out` operand naming the value, whose temporary `x_set` stores after the call (owner, Q12; `42 7`). `x op= e` is `x_set(x op e)`. Predicates: no user expression is left in a static initializer or constructor (C# `const` aside); an arm is picked by `StaticStorage`, never by a type; nothing but `x_set` stores a whole Guarded value (the generator takes the sites from the AST and the emitter's source).
- **D5 (sweep; CodeGen).** **Departure:** ONE `Swept` per module, none per class. The sweep runs in SOURCE order (R-JT): each import with `HasSweep`, each Guarded value, each non-generic type's values at the type's position; it stops at the first throw. A read into a type not yet reached initializes that one value (A5's two-type cell). `Main` first requires its module and rethrows the original exception (owner, Q3); with no Sharpy entry point a module loads on its first use. A GENERIC host (D2's flag) is not swept: each accessor checks its state byte on every use, per closed type (the charter's residue). With no later position for its initializer, a plain store before the first read IS the value: `5 5`, where today and a swept host print `5 7` (A10, A11). Predicate: no accessor of a generic host returns a value in a state below Assigned.
- **D6 (suspension; CodeGen).** C# keeps no returned reference across `await` (CS8178, or a `NullReferenceException` at run time). In an `async def` body a use other than a plain read or a plain store (an `out` operand's temporary crosses the `await`) is a statement `Ensure_x()`, then the backing field; which uses those are is a `SemanticInfo` fact (in `MergeFrom`). Predicate: no accessor's reference is live across an `await`.
- **D7 (operands; Semantic).** `TypeChecker.CheckModifiedArgument` refuses by the operand's resolved symbol (SPY0389; by shape today): a property under `ref` / `out` / `in`, in every host, default or not (owner, Q8); a `const` under `ref` / `out` (`parameter_modifiers.md`: the caller passes a variable). A variable under any modifier and a computed `const` under `in` run. Predicate: no operand the rule admits is a C# error after D4.
- **D8 (cycles; Validation).** One graph after type checking, at Order 251, replacing `StaticInitializerOrderValidator` and `TypeChecker.DetectConstantCycles`. Nodes: each Guarded value and each `const` with an initializer; reads resolve through the checker's bound symbols, never the spelling. Two edge sets, never mixed in one cycle. CERTAIN, between any nodes: a read in a slot the generator classifies `Always` (owner, Q7), so none in a `Conditionally` slot, a pattern or a nested function body. LEXICAL, between `const`s only: any read (today's SPY0278 set, pinned by its tests). A node on a cycle of certain edges, or of lexical edges among `const`s alone, is SPY0278 (its text says "value" for a non-const): no lexical edge closes a cycle through a non-const node, and `5 7 6` keeps running. A cycle neither rule sees is D3's `NameError`. A test asserts the validator's slot map (total over the `Expression` subclasses and `BinaryOperator`) and node kinds equal to the generator's. Predicate: a cycle refused at compile time lies wholly among `const`s, or its every read is evaluated whenever its initializer is, so initializing any of its nodes raises.
- **D9 (retirement; R-KD).** SPY0618 retires in D8's commit; `StaticInitializerOrderMatrixTests` flips by direction: forward cells run, self reads are SPY0278.
- **D10 (interop; rung 3).** A module variable becomes a by-reference C# property: a C# consumer uses it as before, its address too. Generated members carry `[CompilerGenerated]` and discovery skips them. For a module imported by reference it reads `StaticStorage` and `HasSweep` from Sharpy.Core attributes on the member and the load entry — never a name, nor the CLR shape (a C# library's own `ref` static property is Plain) — and the importer's sweep requires the entry at the import's position.
- **Out of contract:** a later module VARIABLE's visibility (SPY0200; N1, #2423; the spec example spells a `const` until P78: owner, Q2); #2151's store arm (P79); a module variable declared twice (#2125, R-CY, P21b); a struct behind a PROPERTY (#2268); `+=` and a `for` target through a closed generic type, a qualified starred target (#2435's class; each excluded with its program). **Open, the owner's:** `in` on a literal `const` (SPY0908 CS8156 today): drop the keyword, or refuse; excluded with its program.
