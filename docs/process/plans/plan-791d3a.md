## Design Decisions

1. **#1967 — normalize at the parser, not the resolver (rung: parser, per `type_annotation_shorthand.md` "the parser normalizes shorthand").** In `ParseTypeArgumentList`, remember the argument's first token before `ParseTypeAnnotation()`; when `isTuple`, the list holds exactly one argument, that token was `(`, and the parsed argument is `{ Name: "tuple", TypeArguments: [] }` (the empty-paren shorthand), drop it so the outer annotation is the zero-arity `tuple`. `tuple[tuple]` (bare name) keeps meaning a 1-tuple of the zero-arity tuple; `tuple[tuple[()]]` keeps meaning a 1-tuple of the empty tuple. The resolver's tuple arm (`TypeResolver.cs:731`) is untouched. Why lower rungs cannot: there is no `.spy`/Core fact; the resolver sees identical ASTs. Observation to file, not fix: bare `tuple` = zero-arity (python: any tuple) — outside this plan.
2. **#1968 — rung 2, four `ToString` overrides through one repr rule.** Element rendering is `Builtins.Repr` (what `Dict.ToString` uses via `using static Builtins`). `DefaultDict.ToString` = `"defaultdict(<factory>, " + _dict.ToString() + ")"` (R-BN placeholder; `_dict` is a `Dict`, so its text IS `Dict.ToString`). `ChainMap.ToString` = `"ChainMap(" + join(", ", _maps.Select(m => m.ToString())) + ")"`. `OrderedDict` and `Counter` do not wrap a `Dict`, so a single Stdlib-internal helper `MappingRepr.Pairs(IEnumerable<KeyValuePair<K,V>>)` → `{k: v, …}` via `Builtins.Repr` serves both (ONE spelling of the braces/comma/colon rule for the non-`Dict`-backed types; the `Dict`-backed ones delegate to `Dict.ToString` — no third spelling). `OrderedDict()` empty prints `OrderedDict()`, `Counter()` prints `Counter()` (python), the other two print their braces. `Counter` orders by `MostCommon()` (python's repr order). The deviation is documented in the XML `<remarks>` of `DefaultDict.ToString` (flows into the generated `docs/stdlib/collections.md`). Rejected: a `Repr()` method instead of `ToString` (the dunder table spells `__str__`/`__repr__` as `ToString`, and `SequenceFormatting.RendersItself` keys on the override).
3. **#1972 — rung 2: `Deque<T> : IReadOnlyCollection<T>, ISized`.** `Count` already exists. Class guard: `SizedProtocolSweepTests` (Stdlib.Tests, reflective over the public types of `Sharpy.Core` and `Sharpy.Stdlib`): every public type implementing `ICollection<T>`, `IReadOnlyCollection<T>` or non-generic `ICollection` must implement `Sharpy.ISized`, minus an explicit exemption roster where every row cites an issue (the sweep's first run at base is the positive control — it must name `Deque`; any OTHER type it names is a sibling cell: fix it in the same commit if it is a one-line interface add with a python-verified `bool()` truth, else file an issue and roster it).
