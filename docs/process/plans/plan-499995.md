## Defect Class

- **Violated contracts (one per phase):**
  1. *Identity:* every type-identity decision keys on ONE canonical, total identity (`SemanticType.CanonicalKey`, with `Equals` agreeing) — never on a display string, and never on record-default equality that a `Symbol` reference or a list makes wrong.
  2. *Signature:* overload identity is ONE key total over the annotation grammar (declaration time) and ONE CLR-mapped key total over resolved types (validation time); no third formula.
  3. *Slot:* the argument seam receives the CLOSED formal at every call route — explicit, inferred, constructor, keyword, deferred-lambda — before the argument is checked; an OPEN formal is a shape hint that binds, never a check that refuses.
  4. *Closure:* a class's supertype closure is computed ONCE, pre-materialization, from the binding, and contains every interface the class will implement — explicit, inherited, CLR-reflected, and dunder-synthesized — so one gate (R-H) sees every instantiation pair.
  5. *Synthesis totality:* every synthesized equality/ordering member is valid C# for every parameter shape {reference, value, `T | None`, `T?`, `object`} and every host kind {class, struct}, in pairs C# requires; the `==` operand slot is the selected dunder's parameter type.
- **Meta-classes:** *Qualified/bare & alias divergence* (identity keys: seven projections of one fact) and *Position/route missing a shared check* (#1797 routes, #1719 operand slot, R-H closure) and *SPY0908 as a net* (#1717 CS0738/SPY0909, #1719 CS0037/CS9135, #1806 CS0216, #1797 CS1503/CS0411) → standard cures: one seam + a position/route matrix; semantic-time refusal by name.
