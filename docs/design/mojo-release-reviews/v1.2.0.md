## Already ahead or covered (keep)

- Pattern matching is a superset of Mojo 1.2's catalog, with a match expression form Mojo lacks.
- Unreachable arms after a wildcard are refused with CPython's wording (SPY0700); Mojo only warns.
- `startswith`/`endswith`, `split("")`, `replace("", x)` edge cases are Python's already.
- Feature gating is a registry (`FeatureFlags` + SPY0331), not a spelling.
- `Bytes.GetHashCode` is content-based; Mojo's `hash`/`hash_bytes` split has nothing to fix here.
- `@inline` needs no decorator: the bracket-attribute route already emits `[MethodImpl(AggressiveInlining)]`.
- Stable diagnostic codes, ratcheting sweeps, emitter purity: unchanged from the KGEN review.

## Recommendations

**R3 (P0) · Own the numerics.** Port fdlibm `s_expm1`/`s_log1p` into `spy/math_module.spy`
(Mojo's `_expm1_accurate` is the same algorithm made branch-free; `.NET`'s `double.ExpM1`/`LogP1`
are the naive formulas, verified, so no lower rung exists). Add the 19 missing `math` functions,
delegating to the BCL where it has an accurate primitive (`Cbrt`, `Asinh/Acosh/Atanh`,
`FusedMultiplyAdd`, `ScaleB`/`ILogB`, `BitIncrement/BitDecrement`) and porting fdlibm for
`erf/erfc/gamma/lgamma`. State each function's accuracy in `docs/stdlib/math.md` and guard the
class with a differential numerics corpus against python3 with per-function ulp tolerances —
Mojo's `float64 log()` was 2e7 ulp off until 1.2 because nothing measured it. Issues: #2349, #2350.

**R-B (P0) · One Python whitespace predicate** for `isspace`, `split()`, `strip()` (and every
other "is a space" site). #2348.

**R-A (P0) · `str.center` rounding and fill characters.** CPython: `left = marg // 2 + (marg & width & 1)`.
Do not copy Mojo (it documents the opposite rounding). Add `str` fill-char overloads or a
single-char-literal → `char` conversion. #2347.

**R4 (P1) · `int.to_bytes`/`from_bytes`/`bit_length`/`bit_count`, `sys.byteorder`** over
`BinaryPrimitives`/`BitOperations`/`BitConverter.IsLittleEndian`. #2351.

**R1 (P1) · Bare tuple match subjects** (`match x > 0, y > 0:`). #2352 (sibling of #2156).

**R2 (P1) · Two CS leaks**: duplicate literal arms (CS0152 → warning + `is`-chain lowering, #2353)
and self-containing struct fields (CS0523 → extend the NameResolver struct-cycle walk to value-type
fields, #2354). Both join the A2 leak corpus.

**R5 (P1) · A printing rule for tagged unions** — constructor spelling with payload reprs,
`Shape.Circle(3)` / `Shape.Empty()`, extending Optional's #2005 ruling; sequence after #2057.
Posted on #2057 for a ruling at `/batch-issues`.

**R6 (P1) · Semicolons**: implement Python's rule (preferred) or record the deviation. #2355.

**R7 (P2) · Docs**: a `lexical_structure.md` spec page (semicolons, commas and trailing commas,
delimiters, token separation, continuation — Mojo's reference page is the template, every block
gated by `check_spec_blocks.sh`), and a "Sharpy for Python developers" guide rendered from
`docs/deviations.yaml` by a `build_tools` script under the `/push` staleness gates.

**R8 (P2) · LSP `deprecated` semantic-token modifier** from `Symbol.DeprecationMessage` (VS Code
renders strikethrough with no client config); `abstract` is the second candidate from the same
fact set.

**R9 (P2) · `case ():`** should be the empty sequence pattern through the same classifier as `[]`;
fold into #1981.

## Rejected (do not re-litigate)

- `if case`, `while case`, leading-dot `.Some(x)` in patterns, `comptime match`, `case == Int`:
  non-Python syntax for things walrus narrowing, bare unit-case patterns and `case int():` do.
  Note the open design tracker #2267 (target-typed `.member` access) before reopening this; Mojo's
  rule there is "without a contextual type, `.member` is an error".
- `where … else "msg"`, `not Trait`, reflection-based `Defaultable` init: no CLR carrier.
- `Tuple[]` rename, walrus restricted to existing variables, `Array[1:3]` as a `Span` view:
  Python's spelling and copy semantics win.
- `hashlib` → `hash`, `isspace` → `is_ascii_whitespace`: Python's names win.
- Everything GPU/SIMD/ownership/allocator: `CompilationTarget`, `TargetAccelerator`,
  `MaybeUninit`, `Layout[alignment]`, `RawFileDescriptor`'s `-1` niche, unified closures, jemalloc,
  per-kernel `--emit`, `mulwide`/`mulhi`, OTLP telemetry.

| Item | Sharpy | Verdict |
|---|---|---|

## Method

Thirteen probe programs for 1.2 and ten for 1.1/1.0 were run through `sharpyc run` from the
session scratchpad (`p_*.spy`, `q_*.spy`), each cell also executed under `python3 -I`; .NET claims
were checked in `dotnet fsi` on the same SDK. Spec and issue claims were checked against
`docs/language_specification/`, `docs/deviations.yaml` and GitHub issue search. Single agent, no
subagents. Items marked "not probed" above are honest gaps, not verdicts.
