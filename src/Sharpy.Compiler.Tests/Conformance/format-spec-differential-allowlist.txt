# Format-spec differential sweep allowlist (FormatSpecDifferentialTests).
#
# Each non-comment line is a cell key (formatspec::<column>::<kind>::<hex-encoded spec>, column =
# engine | static — see FormatSpecDifferentialTests.Column) whose Sharpy vs
# python3 stdout is a KNOWN, reviewed divergence. Every row MUST cite an open issue in a trailing
# '# ... see #NNNN' comment and be DELETED when the divergence is fixed (drain-on-fix: a stale row
# that no longer diverges fails the sweep). The human-readable spec is in the failure output.
#
# No cell is excluded at generation: the '#'-on-float exclusion (HitsKnownGap) was deleted when the
# '#' alternate form was fixed on the float presentations, and the generator draws a whole-valued
# float kind (3.0) so the '#' cells that keep a point and trailing zeros are swept too. Any
# divergence therefore surfaces HERE, as a row citing a fresh issue — never the fixed one.
# (Issue numbers are deliberately absent from this header: the issue-state gate reads a comment
# paragraph's cites onto the rows beneath it.)
