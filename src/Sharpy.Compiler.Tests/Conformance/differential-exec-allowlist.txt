# --- Designed deviation (Axiom 1: .NET semantics win) — PERMANENT ---

# UTF-16 string length and indexing: a .NET string is a UTF-16 code-unit sequence, so
# len("😀") is 2 where CPython (code points) says 1, s[1] is a valid lone surrogate
# where CPython raises IndexError, and escape/normalisation counts follow suit.
# Grapheme/code-point helpers are the opt-in. All four cells are ONE deviation —
# the pre-#1202 allowlist carried only the first because the other three were never
# sampled. deviations.yaml: utf16-string-length, string-indexing-utf16. Permanent.
fixture::strings/string_utf16_len
fixture::strings/string_utf16_indexing
fixture::transition/transition_utf16_len
fixture::string_astral_escape

# 32-bit `int`: `+`/`-`/`*` wrap under .NET's unchecked context and `**` routes
# through the checked CheckedIntPow helper (#905), so `2 ** 40` raises OverflowError
# where CPython's arbitrary-precision int returns 1099511627776. `long` is the 64-bit
# opt-in. deviations.yaml: int-overflow-checked. Permanent.
fixture::integer_power_runtime_checked

# `is` lowers to reference equality, so comparing two boxed value-type operands is
# always False where CPython's small-int cache makes `1 is 1` True. The compiler
# already warns at the use site (SPY0465, asserted by this fixture's .warning
# sidecar), so the deviation is diagnosed rather than silent.
# deviations.yaml: identity-with-value-types. Permanent.
fixture::warnings/is_value_type_warning

# --- Designed deviation (Axiom 3: type safety wins over Python) — PERMANENT ---

# A contextual type closes a collection's element type, so an `int` element of a
# `dict[str, float]` / `list[float]` is widened to double at compile time and prints
# as `5.0` where CPython keeps the int and prints `5`. The alternative is an
# object/union element type, which forfeits static typing.
# deviations.yaml: numeric-widening-in-typed-context. Permanent.
fixture::collections/dict_literal_assignment
fixture::collections/dict_literal_return_type
fixture::collections/list_literal_return_type

# The variadic value form of min()/max() promotes mixed-numeric arguments to a common
# numeric type (#1014), so min(2, 3.0) is 2.0 where CPython returns the unpromoted
# int 2. Matches Sharpy's binary numeric operators (2 + 0.0 == 2.0); the fixture's own
# header marks it a deliberate divergence.
# deviations.yaml: min-max-mixed-numeric-promotion. Permanent.
fixture::builtins/min_max_mixed_numeric

# `...` as a CONCRETE function body lowers to `throw new NotImplementedException()`,
# so the program reports caught exceptions where CPython — for which `...` is just an
# expression statement — returns None. A body annotated `-> int` cannot return None.
# deviations.yaml: ellipsis-body-raises. Permanent.
fixture::basics/ellipsis_concrete_method
