# DeliberatelyPermissive site ratchet — each entry records:
#   filename  count  issue-ref [issue-ref ...]
#
# ONE issue reference PER SITE, in the file's site order: grouping several sites under a single
# issue is how a renumbering passes for a fix (#1640's four Access.cs sites were all re-cited to
# #1678 while one of them was a module-export site that #1674 owns). The ratchet enforces
# refs.Count == count, so a site cannot be hidden behind its neighbour's issue.
#
# When a site is resolved (the type is now tracked), drain the count AND delete its ref. When the
# count reaches 0, delete the entry. Adding a new file or increasing a count requires a new issue.
#
# Measured @ 4ee7e49d3 (#1640, #1645); re-cited per site @ #1640's resolver commit.
#
# The Access.cs site (the module-export-of-an-unhandled-symbol-kind arm) drained @ P5.1 (#1674,
# #1906): the export-type switch now names all six concrete Symbol subtypes, including
# TypeParameterSymbol, so no export reaches a DP mark. The two #1678 CLR-origin tails (general and
# inherited) drained earlier, @ P4b Phase 3.
#
# The Expressions.cs :299 auto site drained @ P5.2 (#1675): the out-auto binding takes the
# resolved callee's parameter type (ValidateCallArguments/ValidateKeywordArguments for a Sharpy
# callee, CheckClrBindingArguments for a CLR one); an unresolved callee refuses by name (SPY0203)
# instead of a standing DP mark.
#
# The Expressions.cs :716 type-ref VALUE-USE site drained @ P5.3 (#1676): a non-primitive
# TypeSymbol/TypeParameterSymbol read as a value now names its own carrier type
# (SelfConstructionOf/TypeParameterType) instead of Unknown; CheckConstructorReference (unchanged)
# re-derives the classification from the symbol independently either way, so every measured
# refusal (SPY0342/SPY0346) is preserved.
#
