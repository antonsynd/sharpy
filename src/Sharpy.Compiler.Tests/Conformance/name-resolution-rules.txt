# under which rule of docs/design/name-resolution.md (N1…N7, S1…S3, the R-xx rulings and the kind refusals).
#
# A row is `<Tag|*> <rule> axis=value,… axis!=value,…`:
#   - the tag is MustRun, MustRefuse, MustRefuseOrThrow, MayRefuse or Unruled; `*` (the seed row only) leaves it to
#     the seed table;
#   - constraints on one row all hold; the values of one constraint are alternatives; `-` is an axis the cell does
#     not carry; `@Class` is a class of the axis (NameResolutionDifferentialTests.RuleTable.cs builds each from the
#     roster or predicate the generator branches on); `mark` holds when the cell's key carries one of the labels.
#   - the axes and where each is read from: RuleTableAxes in the same file.
#
# Totality (RuleTable_EveryCellHasOneRow_AndEveryRowACell, and each sweep): every generated cell matches exactly one
# row, that row's tag and rule are the cell's, and every row has a cell in a pool that reads the table. A verdict
# changes here and in the generator together, or the test is red.
#

# plan-777361 (P78) by splitting the pool on its axes until each part carries one tag and rule, then merging parts
# that differ on one axis. They are edited by hand from here on.
