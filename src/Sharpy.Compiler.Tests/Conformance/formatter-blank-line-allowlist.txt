# Two kinds of entry:
#   stem twin bucket # #issue reason                 — one failing cell
#   pin twin bucket count digest # #issue reason     — every failing stem of a (twin, bucket) key
# twin   — identity | comment
# bucket — instrument | blankLost | blankShape | blankLength | notIdempotent (the class doc defines each)
# count/digest — the failing stems of the key: their number, and the first 16 hex chars of SHA-256 over the
#          sorted, \n-joined stem names ("-" for none) — the code-action-shape-allowlist.txt precedent.
# A failing cell no entry covers is red; a row whose bucket holds now is red (drain on fix); a pin whose count or
# digest differs is red in both directions. The census anchors the entry counts at literals.
