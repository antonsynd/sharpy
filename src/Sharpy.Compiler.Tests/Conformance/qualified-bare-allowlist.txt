# Qualified/bare spelling conformance allowlist (ratchet ledger).

# One `position::shape::sourceSet` cell key per line (see QualifiedBareSpellingConformanceTests).
# A cell whose two spellings disagree on diagnostics, resolved representation or stdout fails the
# ratchet UNLESS its key appears here. `#` starts a comment; blank lines are ignored.
#
# The contract is Design Decision 3 of the import-fidelity batch: A MODULE QUALIFIER CHANGES LOOKUP
# SCOPE, NEVER THE PRODUCED REPRESENTATION. `lib.Shape` and a `from lib import Shape`-bound `Shape`
# name one type, so the two spellings of one program must behave identically. Every entry below is a
# place where they do not, and each is a defect on the qualified side — that is the direction the
# history runs (#1366, #1407, #1410, #1411 were all qualified-only failures).
#
# DO NOT DELETE THIS FILE. Its presence is what arms the ratchet; the sweep throws if it is missing
# rather than passing silently, so removing it cannot be mistaken for relaxing it.
#
# Rules for adding an entry:
#   1. It MUST cite a filed GitHub issue explaining the divergence the cell exposes.
#   2. It MUST correspond to a cell a real run confirms divergent — never allowlist speculatively.
#   3. It is temporary. Delete the line in the same change that fixes the bug ("drain on fix"). The
#      sweep FAILS on a stale entry — an allowlisted cell that has started agreeing — so draining is
#      part of landing the fix rather than a follow-up nobody schedules.
# Any growth is a regression in the contract, not a fact about the code that can be left standing.
