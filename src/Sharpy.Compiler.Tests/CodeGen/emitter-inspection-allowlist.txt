# emitter-inspection-allowlist — EmitterCarrierOnlyConformanceTests.CodeGenInspectionSites_MatchTheAllowlist.
#
# Every site where CodeGen still INSPECTS a SemanticType or Symbol instead of reading a materialized
# fact (Critical Rule 2; P82 class issue #2443, contract item 6). Since P82 the SemanticType and Symbol
# hierarchies are not carriers: CarrierHierarchyRoots is empty and every type assignable to either
# root is inspection-denied in CodeGen/, except that TypeSyntaxMapper.cs may name them (contract
# item 1: the emitter may pass a SemanticType to TypeSyntaxMapper but may not inspect one outside it).
#
# Row: file | kind | name | count | cite=#N | note    (file = a CodeGen/ file name; one row per key)
# Kinds, as the test measures them:
#   type-name         a hierarchy type named (declaration, cast, pattern, generic argument, static
#                     call) — Roslyn identifier scan, per (file, type); TypeSyntaxMapper.cs exempt
#   type-name-compare a name compare on a denied type, per (file, shape) — Roslyn syntax:
#                     name-compare = `r.Name`/`r?.Name` under ==, !=, `is` or a switch, `r` a parameter,
#                     explicitly typed local or pattern designation of a denied type; name-subpattern =
#                     `T { Name: … }` with T denied. `var`-bound receivers and fields are not bound (no
#                     semantic model); union-case compares are name-lookup rows. TypeSyntaxMapper.cs exempt
#   type-read         invocations of a reflected accessor — every public SemanticInfo/SemanticBinding
#                     method returning a SemanticType or an IEnumerable<T> of one — or of the emitter
#                     helper GetExpressionSemanticType, per (file, accessor)
#   name-lookup       predicate: a lambda `x => x.Name ==` lookup over a member collection (2-line
#                     window, decorator/keyword-argument/body lookups excluded); union-case-compare:
#                     `.Name == "Some"/"Ok"/"Err"/"None"` (or WellKnownCaseNames.*)
#   declaration-line  DeclarationLine references, per file
#
# Ratchet, both ways: more sites than the count fails (a NEW inspection: materialize the fact);
# fewer fails (STALE: lower the count, delete the row at 0, in the commit that removed the sites);
# sites without a row fail; a row naming a file that no longer exists fails. Drains to empty.
# Counts measured by the test's own scanner at 0ea13e3a6; the type-name-compare rows and the
# reflected type-read rows were seeded at the scanner's counts by plan-1faae3 Phase 1.
